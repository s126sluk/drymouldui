    How these numbers are counted
    • Status counts come straight from the status field in pmleads_db at the moment of the last sync. The placeholder "select" status is left out.
    • New leads this week uses the date each contact was added to pmleads_db.
    • Weeks run Monday to Sunday, Sydney time. The striped column is the week in progress.
    • Requests use the date field in pmrequests_db. A request counts as approved when its request status is approved.
    • A quote stays open for 21 days, so the approval rate for the most recent three weeks can still rise.
    • Agency rates use the agency recorded on the contact linked to each request.
